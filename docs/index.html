Todavía no hay un build WebGL publicado acá.

El build viejo (sep-2024) no sirve para GitHub Pages: usa .gz sin "Decompression Fallback", y Pages no puede mandar el header Content-Encoding que ese loader necesita.

Falta: rebuild en Unity con Publishing Settings → Decompression Fallback: ON (+ Compression Format: Brotli), luego correr scripts/deploy-webgl.sh con la carpeta del build nuevo.
